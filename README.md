# Python Security Mini Projects

Two beginner security tools built during my CodeOrbit Tech internship.

## Projects
1. Caesar Cipher Encryption Tool – encrypt/decrypt text with a shift key
2. Password Strength Checker – checks length, upper/lowercase, digits and special characters

## Technologies Used
- Python 3

## Setup Instructions
1. Install Python 3 from python.org
2. Clone the repo:
```
git clone https://github.com/PamilaV/codeorbit-internship-tasks.git
```
3. Go to the folder:
```
cd codeorbit-internship-tasks
```
4. Run:
```
python caesar.py
python password.py
```
